# Mori 使用说明

## 开始写作

按 `⌘N` 创建文章并选择模板。写作模式中，输入 `# `、`## `、`- `、`1. `、`> ` 会创建相应段落。选中文字后显示格式工具，也可以使用文章上方的工具条和菜单栏。

输入 `/` 后选择标题、列表、表格、代码块、公式或图表。代码块左上角可填写语言，例如 `swift`、`javascript`、`python`；在代码块内按 `⌘↩` 可以回到普通段落。

双击公式可以修改 LaTeX；双击图片可以修改图片路径与描述。`mermaid` 代码块下方会显示图表，修改代码时会更新。

## 界面语言

通过 **Mori → 语言** 或 **写作环境（⌘,）→ 偏好 → 界面语言** 选择「跟随系统」「English」或「简体中文」。首次启动默认使用英文；选择「简体中文」立即切换中文。主动选择「跟随系统」后，才会使用首选系统语言，未支持的系统语言使用英文。切换立即生效，选择会在下次启动时保留。

语言切换只改变界面文案，不改写文章、Front Matter、光标与撤销历史。主题导入、导出与恢复默认外观不会改变语言偏好。macOS 系统对话框仍使用系统语言。

## 博客文件夹

按 `⌘⇧O` 选择自己的博客内容目录，侧栏会递归显示 `.md`、`.markdown`、`.mdown` 和 `.mkd` 文章，并标明子目录路径。隐藏目录、依赖目录与构建目录会跳过。

侧栏搜索支持文件名与路径。开启“搜正文”后也检索文章内容；文件新增或移动后点击刷新。点击文章即可在标签页中打开，打开同一文件会复用已有标签。

右上角侧栏按钮打开文章信息，可切换大纲、博客元信息和本机历史。

## 保存与恢复

新建文章首先作为本机草稿保留。按 `⌘S` 保存为真正的 Markdown 文件后，后续修改默认自动保存。写作环境的“偏好”页可以关闭文件自动保存，未命名草稿恢复功能始终保留。

标签上的圆点代表有修改未写入文件。退出应用前会再次刷新稿件与恢复档案。恢复档案位于 `~/Library/Application Support/Mori/session.json`，不要在使用应用期间手动修改它。

外部程序更改或移动了文件时，Mori 会停止覆盖文件并提示冲突。可以“另存当前稿件”或“载入磁盘版本”；载入前的原稿会保留在历史中。

手动保存留存版本，自动保存每分钟最多留一个版本，每篇最多 50 个。历史不会随文章文件自动迁移到其他设备。

关闭未保存标签时可选择保存、取消或放弃。放弃会移除这个标签的未保存稿件；关闭窗口与退出应用会保留恢复档案。

## 图片

先把文章保存到文件，再通过工具条、剪贴板或拖放导入图片。Mori 会建立同目录 `assets/` 文件夹，并为每张图片生成不会重名的文件名。Markdown 使用相对路径，移动博客时一起移动 `assets/`。

预览只读取当前文章目录和已选博客文件夹中的本地图片。工作区以外的相对图片需要将所在博客根目录选为文章库。HTTPS 图片可使用远程链接。

## 博客元信息

选择 Astro、Hugo 或 Jekyll 模板会自动生成 Front Matter。博客面板支持常用字段，只对用户修改的字段进行更新。Astro 保持 `pubDate` 与已有 `heroImage` 键名。

摘要可以多行输入；标签和分类用逗号分隔。复杂 YAML 内容可以在源码模式中直接编辑。无效 YAML 会阻止面板应用操作，原文会保留。

## 源码与分栏

`⌘⇧M` 切源码，`⌘⇧P` 切分栏，`⌘⇧R` 返回写作模式。源码模式保留完整文本，并支持括号配对、行号和语法高亮。分栏的预览跟随源码滚动比例。

包含脚注、MDX、原始 HTML 或其他无法安全往返的扩展语法时，写作模式会自动改为源码模式。不会执行 MDX 或网页脚本。

## 写作环境

按 `⌘,` 打开写作环境：

- “外观”调整基础主题、背景图、位置与画面参数、遮罩、纸面及侧栏透明度。
- “文字”调整字体、字号、行距、纸宽和文章 CSS。
- “偏好”切换界面语言，调整自动保存、拼写检查、行号和每篇写作目标。
- 右上角菜单可导入、导出主题，或恢复默认设置。

自定义 CSS 推荐只使用 `.markdown-content` 范围内的选择器，例如：

```css
.markdown-content h1 { letter-spacing: -0.04em; }
.markdown-content blockquote { border-left-width: 2px; }
```

`⌘⇧F` 开启专注模式，`⌘⇧T` 开启打字机模式。专注模式隐藏侧栏与工具栏，淡化非当前段落；状态栏按钮可以随时退出。

## 导出

通过右上角分享按钮或“文件”菜单导出 HTML、PDF，或复制 Markdown / HTML。

HTML 会嵌入可访问的本地图片、KaTeX 字体和文章样式；远程图片仍保留链接。PDF 使用系统打印生成，纸张默认为 A4。“打印 / 存为 PDF”可以自行设置打印选项。

| 新建文章 / 空白草稿 | `⌘N` / `⌘⇧N` |

| 保存 / 另存为 | `⌘S` / `⌘⇧S` |
| 关闭标签 | `⌘W` |

| 加粗 / 斜体 / 链接 | `⌘B` / `⌘I` / `⌘K` |
