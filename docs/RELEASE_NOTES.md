Mori 的首个公开版本，为博客写作者提供直接写作、源码编辑和分栏预览。

- 原生 macOS 窗口、文章库、多标签、大纲导航与博客元信息。
- 表格、任务列表、代码高亮、公式、Mermaid、图片粘贴与相对路径管理。
- 自动保存、未命名草稿恢复、外部修改冲突保护与本机历史。
- 自定义背景、布局、文字和 CSS；主题导入导出。
- HTML / PDF 导出与系统打印。

适用于 macOS 14+，ZIP 和 DMG 均包含 Apple Silicon / Intel 通用应用。文件校验见 SHA256SUMS.txt。应用使用 ad-hoc 签名，尚未使用 Apple Developer ID 公证；首次启动处理见 README 安装说明。

对于脚注、MDX、原始 HTML 等扩展语法自动使用源码模式保留原文。此版本没有云端发布与同步服务。
